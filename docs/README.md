# docs/

The thinking behind the carer map, grouped by area. If you want to understand or defend the
map, start with **methods**. To see how the data is fetched and built, see
[`../scripts/README.md`](../scripts/README.md).

| [methods/DATA.md](methods/DATA.md) | What carer data exists at which geographies, and what is plottable. |

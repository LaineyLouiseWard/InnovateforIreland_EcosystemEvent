# Innovate for Ireland — Ecosystem iScholars AI Workshop

Starter repo for my group at the Ecosystem iScholars AI workshop (hands-on with Claude Code, facilitated by Jonathan McCrea).

- [`EVENT_INSTRUCTIONS.md`](EVENT_INSTRUCTIONS.md) — what the day is: format, run-of-show, my roles, and the logistics to settle.
- [`BRAINSTORM.md`](BRAINSTORM.md) — the two candidate problems (UCD housing finder, carer vulnerability map) with their data sources.

On the day the group picks one problem and builds it out in this repo. The sister project, [the-indices-of-ireland](https://github.com/LaineyLouiseWard/the-indices-of-ireland), is a worked example of the same pattern: keyless open data turned into an interactive county map with Leaflet.

## Environment

```bash
conda env create -f environment.yml
go InnovateforIreland_EcosystemEvent     # cd into the folder and activate the env
```

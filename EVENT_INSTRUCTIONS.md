# Ecosystem iScholars — Event 2: AI Workshop (Claude Code)

Logistics and instructions for the workshop, from the planning call with the facilitator.

**Facilitator:** Jonathan McCrea (broadcaster, Newstalk *Futureproof*; founder of Whipsmart Media, SCI:COM, and *Get Started with AI*, his paid AI-training arm). Communicator first; runs this as a repeatable product. His usual audience is non-technical business teams, and Claude Code is a step more technical, which is why he wants a baseline check and group leads.

**Topic:** the basics of AI, hands-on with Claude Code.
**Date:** the 8th, in person.
**Bring:** a laptop.

## Pre-meeting (planning Zoom)

A short call ahead of the day. Jonathan's stated purpose:

- Assess technical ability (a baseline of zero is completely fine).
- Identify who will install Claude Code on their machine.
- Walk through the session and answer questions in advance.

## Format (his standard)

- Half-day, in person, hands-on, team-based.
- Three-part arc: AI fundamentals without jargon, then the skills you'll use daily, then where the cutting edge is.
- Heavy on live demos, group exercises, and participants' own use-cases.

## Likely run-of-show

1. Framing talk: agents vs chatbots ("it has hands"), no jargon.
2. Live demo: Jonathan drives Claude Code, opening a project and doing a multi-step edit/run.
3. Break into small groups, each with a pre-assigned lead whose laptop already has Claude Code installed. The lead drives; the others watch and suggest.
4. Guided hands-on exercise: each group picks a real task and builds it while he circulates.
5. Share-back, and where to go next.

## My roles

**On the planning Zoom (co-lead):**
- Run the agenda with Jonathan.
- Gauge where the cohort is (never used AI / chatbot only / codes a bit / already uses Claude Code).
- Nominate and confirm the group leads (people comfortable installing software and driving a terminal or editor).
- Settle logistics: who installs beforehand, accounts and auth, everyone vs leads only.

**On the day (group lead):**
- Drive Claude Code for my group, unblock installs and permissions, and keep the exercise moving.
- Seed a good example use-case. The sister project (The Indices of Ireland map) is exactly this kind of example: keyless open data turned into an interactive county map.

## To settle on the call

- Installs are the number-one failure point. Confirm exactly what each lead needs working beforehand: Claude Code installed, signed in, and a sample project open.
- Which accounts and auth are required, and whether everyone installs or only the leads.
- How many groups, and who leads which.
